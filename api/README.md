# Cliniq — Backend API

Express + TypeScript + Prisma backend for the Cliniq doctor appointment platform.

## Start

```bash
npm install
npx prisma db push
npm run start
```

## Scripts

| Script | Description |
|--------|-------------|
| `npm run start` | Start dev server with ts-node-dev |
| `npm run build` | Compile TypeScript to dist/ |
| `npm run compile` | Run compiled JS from dist/ |
| `npm run lint:fix` | Fix ESLint issues |
